## Advanced Hole and Hole Series (separate domains)

* **Advanced Hole**: `UNSUPPORTED_WITH_REASON` (`HW_ADVANCED_HOLE_NOT_IMPLEMENTED`). Advanced Hole is a separate native feature; its element stacks are parsed and kept, but no creation adapter is implemented and no live feature has been created or verified. API surface: `IFeatureManager.AdvancedHole2(NearElementArray, FarElementArray, UseBaselineDimensions, IsCustomCallout, IsDepthUptoTip)`.
* **Hole Series**: `BLOCKED_BY_CONFIRMED_SOLIDWORKS_2025_LIMITATION` (`HW_HOLE_SERIES_NOT_CREATABLE`). the installed SOLIDWORKS 2025 API has no entry point that creates a Hole Series feature (only a reader object). Evidence: tools/read_sw_typelib.py against the installed SOLIDWORKS 2025 type libraries; checked swFeatureNameID_e (no Hole Series member), ISldWorks, IModelDoc2, IModelDocExtension, IAssemblyDoc, IFeatureManager (no method named for Hole Series); `IHoleSeriesFeatureData2` is a reader. A test re-checks this against the installed library.

Neither is ever replaced by a basic Hole Wizard hole.
