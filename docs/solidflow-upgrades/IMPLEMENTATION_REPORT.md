## 5. Not implemented / known limits (honest list)
* **Section / detail / auxiliary views** are not generated by default. Blind-hole depth and counterbore size are flagged `review_required` (97 items across the 18-part batch). (Updated below if the section-view work lands.)
* Radial holes on curved faces: the visible edge is not a circle, so no callout is generated (`HOLE_EDGE_NOT_FOUND`, high severity).
* Revolved bosses / shafts, fillet radii and chamfers are listed for review, not dimensioned automatically.
* Multibody and freeform parts are routed to review.
* No second sheet is created: a view that does not fit is scaled down and labelled; if it still does not fit it becomes a `high` issue.
* Native `.slddrt` is produced next to every `.drwdot`; a user-uploaded `.slddrt` alone is refused (needs its `.drwdot`).
* Student Edition adds a license line to every PDF; this is not part of the pipeline.
* A hung COM call cannot be force-killed without killing a SOLIDWORKS session that may be the user's; the watchdog flags the part and requests cancellation.
* Not run: a live OpenAI extraction with a material callout (needs the API key and a budget go-ahead); a customer reference drawing comparison; engineer review (Gate F).
